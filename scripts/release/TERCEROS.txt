Software de terceros incluido con NeoHEN / Third-party software shipped with NeoHEN
====================================================================================

NeoHEN arranca estos programas y lleva compiladas estas librerías, pero no
son suyos. Los payloads son los binarios que publican sus autores, sin
modificar. Gracias a todos ellos. Lista completa y estado de cada licencia:
docs/third-party-licences.md en el código de NeoHEN.

NeoHEN starts these programs and has these libraries compiled in, but does
not own them. The payloads are their authors' release binaries, unmodified.
Thanks to all of them. Full list and the state of each licence:
docs/third-party-licences.md in NeoHEN's source.

NeoHEN, NeoWEB y el servicio de temas / NeoHEN, NeoWEB and the theme service:
  https://github.com/neox69/NeoHEN — GPL-3.0 (LICENSE en el código / in the
  source; https://www.gnu.org/licenses/gpl-3.0.txt). El código de cada
  versión es la etiqueta v<versión> del repositorio. / The source of each
  release is the repository's v<version> tag.
